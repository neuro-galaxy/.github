# Neuro Galaxy

Neuro Galaxy is a project to build, train, and deploy foundation models for neuroscience. We provide the following packages:

<table>
  <tr>
    <td align="center">
      <a href="https://github.com/neuro-galaxy/temporaldata">
        <img src="https://temporaldata.readthedocs.io/en/latest/_static/temporaldata_logo.png" width="100"/>
      </a>
      <br />
      <b>temporaldata</b>
      <br />
      Library for handling temporal neural data with efficient data structures and processing tools
      <br />
      <a href="https://temporaldata.readthedocs.io/en/latest/index.html">View Documentation</a>
    </td>
    <td align="center">
      <a href="https://github.com/neuro-galaxy/brainsets">
        <img src="https://brainsets.readthedocs.io/en/latest/_static/brainsets_logo.png" width="100"/>
      </a>
      <br />
      <b>brainsets</b>
      <br />
      A collection of pre-processed neuroscience datasets ready for model training and evaluation
      <br />
      <a href="https://brainsets.readthedocs.io/en/latest/index.html">View Documentation</a>
    </td>
    <td align="center">
      <a href="https://github.com/neuro-galaxy/torch_brain">
        <img src="https://torch-brain.readthedocs.io/en/latest/_static/torch_brain_logo.png" width="100"/>
      </a>
      <br />
      <b>torch_brain</b>
      <br />
      A PyTorch-based library for building transformer models for neuroscience applications
      <br />
      <a href="https://torch-brain.readthedocs.io/en/latest/index.html">View Documentation</a>
    </td>
  </tr>
